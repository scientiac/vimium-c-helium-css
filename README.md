# vimium-c-helium-css
A  css style for Vimium C that looks good on helium browser.

## To apply:

1. Go to Vimium Options
2. Scroll to `Custom CSS for Vimium C UI`.
3. Paste the contents of `style.css` there.

## To enable `Run on chrome://*/*/ pages` and on the `Native New Tab Page`:

> [!WARNING]
> This grants extensions more power, so the browser will become more insecure.

1. Go to `about:flags`.
2. Search for `extensions-on-chrome-urls`.
3. Enable the option.
